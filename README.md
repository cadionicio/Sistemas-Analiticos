## Acerca de

Este repositorio reúne ocho sistemas desarrollados para el curso de **Sistemas Analíticos**. Cada uno resuelve un problema de gestión distinto (estrategia, modelo de negocio, abastecimiento, inventarios, costeo, distribución, mantenimiento y atención al cliente) y aplica las cuatro capas de la analítica:

| Capa | Pregunta que responde |
|---|---|
| **Descriptiva** | ¿Qué está pasando? |
| **Diagnóstica** | ¿Por qué está pasando? |
| **Predictiva** | ¿Qué va a pasar? |
| **Prescriptiva** | ¿Qué conviene hacer? |

Todos los sistemas funcionan **sin conexión a internet**, guardan sus datos en **SQLite** y se pueden usar como página web y como aplicación de escritorio para Windows.

### 09 · IA Lean Six Sigma

![Estado](https://img.shields.io/badge/estado-en%20construcción-orange?style=flat-square)

¿Cuánto dinero pierde una organización por un proceso que nadie ha medido bien?

Un sistema que guía paso a paso por las cinco etapas de **DMAIC** (Definir, Medir, Analizar, Mejorar, Controlar), aplica las herramientas estadísticas de cada etapa sobre datos reales y termina con lo que importa: **cuánto se ahorra** al implementar la mejora.

Sirve para cualquier tipo de organización. La pregunta es qué encontrará en la tuya.
