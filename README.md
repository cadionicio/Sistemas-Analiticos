## Acerca de

Este repositorio reúne siete sistemas desarrollados para el curso de **Sistemas Analíticos**. Cada uno resuelve un problema de gestión distinto (estrategia, modelo de negocio, abastecimiento, inventarios, costeo, distribución y mantenimiento) y aplica las cuatro capas de la analítica:

| Capa | Pregunta que responde |
|---|---|
| **Descriptiva** | ¿Qué está pasando? |
| **Diagnóstica** | ¿Por qué está pasando? |
| **Predictiva** | ¿Qué va a pasar? |
| **Prescriptiva** | ¿Qué conviene hacer? |

Todos los sistemas funcionan **sin conexión a internet**, guardan sus datos en **SQLite** y se pueden usar como página web y como aplicación de escritorio para Windows.
